Aria Date Picker — دیت‌پیکر شمسی و میلادی

یک فایل جاوااسکریپت، بدون هیچ وابستگی. تمام ظاهر برنامه داخل همان فایل قرار دارد و کلاس‌ها با پیشوند adp- نام‌گذاری شده‌اند تا با برنامه‌ی شما تداخل نکنند.

تک‌فایلی و بدون Dependency تقویم شمسی + میلادی حالت بازه (از — تا) محدودسازی بازه‌ی انتخابی تعطیلات از JSON و اینترنت دسترسی‌پذیر با کیبورد

۰ راه‌اندازی در ۱۰ ثانیه

فقط فایل aria-datepicker.js را وارد کنید و یک ورودی بسازید. استایل‌ها به‌صورت خودکار تزریق می‌شوند.

<input id="birthday" placeholder="تاریخ تولد">
<script src="aria-datepicker.js"></script>
<script>
  AriaDatePicker.create('#birthday', { calendar: 'jalali' });
</script>
مقداری انتخاب نشده است.

۱ انتخاب تاریخ شمسی و میلادی

با گزینه‌ی calendar می‌توانید 'jalali'، 'gregorian' یا 'both' (نمایش هم‌زمان دو تقویم) را انتخاب کنید.

AriaDatePicker.create('#demo-both', {
  calendar: 'both',            // هر دو تقویم در یک پنل
  primaryCalendar: 'jalali',   // تقویم اصلی (مبنای مقدار خروجی)
  initialDate: 'today',        // نمای شروع روی امروز
  defaultDate: '1404/01/01'    // مقدار پیش‌فرض کادر ورودی
});
با کلیک روی کادر، هر دو تقویم کنار هم نمایش داده می‌شوند.

۲ تاریخ پیش‌فرض و نمای شروع

گزینه‌ی initialDate تعیین می‌کند پنل هنگام باز شدن روی چه ماهی باز شود ('today'، 'now'، تاریخ انتخابی، یا 'selected') و گزینه‌ی defaultDate مقدار پیش‌فرض کادر را تعیین می‌کند. 

AriaDatePicker.create('#demo-default', {
  calendar: 'jalali',
  initialDate: '1405/01/01',   // پنل روی فروردین ۱۴۰۵ باز می‌شود
  defaultDate: '1403/06/15',   // کادر با این تاریخ پر می‌شود
  placeholder: 'تاریخ قرارداد'
});
پنل روی فروردین ۱۴۰۵ و کادر روی ۱۴۰۳/۰۶/۱۵ تنظیم شده است.

۳ حالت بازه «از تاریخ تا تاریخ»

با range: true می‌توانید یک بازه انتخاب کنید. با حرکت ماوس پیش‌نمایش بازه نمایش داده می‌شود و در حالت تأییدی (confirmMode) مقدار فقط با دکمه‌ی تأیید ثبت می‌شود.

AriaDatePicker.create('#demo-range', {
  calendar: 'jalali',
  range: true,
  monthsPerPanel: 2,          // دو ماه در هر پنل
  closeOnSelect: false,
  onChange: function (v) {
    console.log(v.from.text, 'تا', v.to && v.to.text);
  }
});
هنوز بازه‌ای انتخاب نشده است.

۴ محدود کردن بازه‌ی انتخابی

با limits می‌توانید انتخاب را آزاد یا محدود به یک بازه کنید. حالت‌های free | range | before | after پشتیبانی می‌شوند؛ همچنین minDays/maxDays طول بازه، disabledDays روزهای هفته و disabledDates روزهای مشخص را غیرفعال می‌کند. 

AriaDatePicker.create('#demo-limited', {
  calendar: 'jalali',
  range: true,
  limits: {
    mode: 'range',            // فقط بین دو تاریخ
    from: '1404/01/01',
    to:   '1404/06/31',
    minDays: 2,               // حداقل ۲ روز
    maxDays: 20               // حداکثر ۲۰ روز
  },
  disabledDays: [],           // مثلاً [5] برای غیرفعال کردن همه‌ی جمعه‌ها
  disabledDates: ['1404/01/13', '1404/03/14']
});
روزهای بیرون بازه و روزهای غیرفعال‌شده قابل کلیک نیستند.

۵ تعطیلات: ورود با فایل JSON

کافی است یک فایل JSON با ساختار زیر بسازید و آدرس آن را به گزینه‌ی holidayJson بدهید (یا خود آبجکت را با holidays بدهید). روزهای تعطیل قرمز و مناسبت‌ها در فهرست پایین تقویم نمایش داده می‌شوند. فایل نمونه در همین پوشه با نام holidays-sample.json قرار دارد. 

{
  "weekends": { "jalali": [5], "gregorian": [0, 6] },
  "jalali": {
    "1405/01/01": "جشن نوروز",
    "1405/01/13": { "title": "روز طبیعت", "type": "holiday" }
  },
  "gregorian": { "2026-12-25": "کریسمس" }
}

// و در جاوااسکریپت (خواندن از فایل):
AriaDatePicker.create('#demo-json', {
  calendar: 'both',
  holidayJson: 'holidays-sample.json',
  showHolidayList: true,
  showExportButton: true      // دکمه‌ی JSON برای ذخیره‌ی داده‌های دانلودشده
});

// یا معرفی مستقیم داده‌ها بدون فایل:
AriaDatePicker.create('#demo-json', {
  holidays: { jalali: { '1405/01/01': 'جشن نوروز' } }
});
تعطیلات رسمی ثابت بارگذاری شده‌اند (نسخه‌ی درون‌صفحه‌ای همان داده‌های فایل نمونه است).
خواندن فایل JSON با fetch انجام می‌شود؛ بنابراین اگر صفحه را مستقیم از روی فایل (file://) باز کرده‌اید، مرورگر اجازه‌ی خواندن فایل را نمی‌دهد. صفحه را با یک وب‌سرور ساده اجرا کنید: python -m http.server 8000 یا npx serve و سپس آدرس http://localhost:8000 را باز کنید. در همین حالت‌که فایل را از روی دیسک باز کرده‌اید، دمو با داده‌ی درون‌صفحه‌ای کار می‌کند و دکمه‌ی «بارگذاری از فایل JSON» پیام خطای مدیریت‌شده نشان می‌دهد.

۶ دریافت خودکار تعطیلات از اینترنت

اگر سیستم کاربر به اینترنت وصل باشد، تعطیلات (شامل تعطیلات قمری مثل محرم و رمضان) به‌صورت خودکار از سرویس‌های عمومی دریافت و در حافظه‌ی محلی مرورگر ذخیره می‌شوند؛ با متد downloadHolidays() می‌توانید همان داده را در قالب فایل JSON ذخیره کنید. 

AriaDatePicker.create('#demo-online', {
  calendar: 'both',
  autoFetch: 'today',   // 'off' | 'today' | 'visible'
  countryCode: 'IR'
});

// ذخیره‌ی تعطیلات دریافت‌شده در فایل JSON
const api = AriaDatePicker.get(document.querySelector('#demo-online'));
api.downloadHolidays('holidays-1405.json');
api.getHolidays();                    // فهرست تعطیلات یک سال
api.fetchHolidays();                  // دریافت مجدد (Promise)
سرویس‌های پیش‌فرض: holidayapi.ir، persiancalapi.ir، api.keybit.ir برای تقویم شمسی و holidayapi.ir / date.nager.at برای میلادی. اگر یکی در دسترس نباشد، سرویس بعدی در زنجیره امتحان می‌شود. می‌توانید سرویس دلخواه خود را با AriaDatePicker.addProvider() اضافه کنید. در صورت نبودن اینترنت، داده‌ی ذخیره‌شده‌ی قبلی در مرورگر استفاده می‌شود و پیام «آفلاین» نمایش داده می‌شود.

۸ استفاده در فرم‌ها (ارسال مقدار به سرور)

اگر هدف یک div باشد، می‌توانید با name یک فیلد مخفی برای ارسال در فرم بسازید؛ مقدار آن تاریخ میلادی ISO در قالب YYYY-MM-DD است.

// div به‌عنوان فیلد + فیلد مخفی برای فرم
AriaDatePicker.create('#demo-form-field', {
  calendar: 'jalali', name: 'trip_date', range: false
});
// <input type="hidden" name="trip_date" value="2026-10-11">

۱۱ متدهای عمومی (API)

const dp = AriaDatePicker.create('#el', { calendar: 'jalali', range: true });

dp.open(); dp.close(); dp.toggle();     // باز/بسته کردن
dp.getDate();                           // تاریخ انتخاب‌شده (شیء کامل + معادل دو تقویم)
dp.getRange(); dp.getRangeText();       // بازه‌ی انتخاب‌شده
dp.getValue(); dp.getText();            // { from, to, text, jalali, gregorian }
dp.getGregorianDate();                  // Date جاوااسکریپت
dp.getJalali(); dp.getGregorian();      // معادل شمسی/میلادی
dp.setDate('1405/01/01');               // تنظیم مقدار
dp.setRange('1405/01/01', '1405/01/13');// تنظیم بازه
dp.clear(); dp.goToday();               // پاک کردن / رفتن به امروز
dp.setLimits({ mode: 'range', from: '1405/01/01', to: '1405/06/31' });
dp.setCalendar('gregorian'); dp.setOptions({ theme: 'dark' });
dp.getHolidays(1405, 'jalali');         // فهرست تعطیلات یک سال
dp.loadHolidays('holidays.json');       // بارگذاری فایل تعطیلات
dp.fetchHolidays(true);                 // دریافت مجدد از اینترنت
dp.downloadHolidays('holidays.json');   // ذخیره‌ی تعطیلات در فایل JSON
dp.exportHolidays();                    // خروجی JSON به‌صورت رشته
dp.destroy();                           // حذف کامل

// توابع کمکی مستقل
AriaDatePicker.format('1405/01/01', 'dddd D MMMM YYYY', 'jalali'); // جمعه ۱ فروردین ۱۴۰۵
AriaDatePicker.convert('1405/01/01', 'jalali', 'gregorian');       // { y: 2026, m: 3, d: 21 }
AriaDatePicker.toDate('1405/01/01', 'jalali');                     // Date
AriaDatePicker.parse('۱۴۰۵/۰۱/۰۱');                                 // { calendar, y, m, d, jdn }
همه‌ی متدهای بالا در این صفحه فعال هستند؛ می‌توانید در کنسول مرورگر امتحان کنید: AriaDatePicker.instances فهرست همه‌ی نمونه‌های فعال را برمی‌گرداند.

۱۲ کیبورد و دسترسی‌پذیری

  • Enter / Space / ↓ باز کردن پنل و انتخاب روز
  • ← → ↑ ↓ حرکت بین روزها (متناسب با جهت تقویم شمسی)
  • Page Up / Page Down ماه قبل/بعد — همراه Shift سال قبل/بعد
  • Home / End ابتدا و انتهای هفته
  • Esc بستن پنل (در حالت تأییدی، بازگشت به مقدار قبلی)
  • ساختار ARIA کامل: role="dialog"، role="grid"، aria-selected، aria-label فارسی برای هر روز

۱۳ جلوگیری از تداخل با برنامه‌ی اصلی

  • همه‌ی کلاس‌های CSS با پیشوند adp- ساخته می‌شوند (مثلاً .adp-day، .adp-popup) و فقط روی عناصری که خودِ دیت‌پیکر می‌سازد اعمال می‌شوند.
  • متغیرهای رنگ به‌صورت CSS Variable با پیشوند --adp- تعریف شده‌اند و به بیرون سرریز نمی‌کنند.
  • دیت‌پیکر هیچ استایل سراسری (global) برای تگ‌هایی مثل body، input یا button تعریف نمی‌کند.
  • در صورت نیاز، با گزینه‌ی prefix: 'my-picker-' می‌توانید پیشوند را هم کاملاً اختصاصی کنید.
  • کل کتابخانه داخل یک IIFE بسته است و فقط یک شیء سراسری به نام AriaDatePicker می‌سازد (سازگار با AMD و CommonJS).
